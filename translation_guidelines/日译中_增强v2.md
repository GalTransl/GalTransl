# 翻译原则（轻小说/视觉小说特化版）

适用对象：将日本轻小说/视觉小说翻译为中文的翻译 AI  
版本：v2.0
依据：结合中文现代小说语感与 ACG 文化语境，在“传统文学翻译”与“网络流行语”之间寻找最适宜轻小说的阅读平衡点。

## 目的

本文件的目标，不是把日文逐字搬成中文，而是把原文的意义、情绪、节奏、人物声音，化入自然、顺畅、带有“轻盈感”的中文。

核心要求：**忠于原意，拒绝生硬翻译腔；要说“人话”，要符合年轻人的阅读直觉，但绝不滥用网络烂梗来强行接地气。**

## 优先级顺序

发生冲突时，按以下顺序取舍：

1. 保留原文情节信息与核心逻辑。
2. 保留人物性格（傲娇、三无、热血等）、情绪爆发力与画面感。
3. 译成自然、地道、**日常口语化**的中文（说人话）。
4. 维持 ACG 作品特有的“日轻风味”，但底线是中文读起来不别扭。
5. 原句的语法结构、修饰语位置，能舍则舍，该拆就拆。

## 总原则

1. **先化，再译。** 脑海里先有“画面”和“声音”，再决定中文怎么打字。
2. **要“轻盈”，不要“厚重”。** 轻小说和视觉小说的受众习惯快节奏阅读。句子要通透，少用冷僻字词，少用复杂的长句叠叠乐。
3. **拥抱日常感，克制书面语。** 除非角色设定是古人、贵族或在作报告，否则日常对话和心理活动应尽量接近现代年轻人的日常表达，避免“文绉绉”。
4. **禁止“梗排泄”。** 可以使用符合语境的生动词汇，但**严禁**随意替换成中国特有的、容易过期的网络流行烂梗（如：绝绝子、蚌埠住了、泰裤辣等），除非原文就是极其特定的日本网络死语并需要等效替换。
5. **视听感优先。** 视觉小说有文本框，轻小说多短段落。要想象这些字是伴随立绘、语音和 BGM 出现的，节奏感（气口、停顿、吐槽的包袱）至关重要。

## 日轻翻译的专项目标与痛点处理

日轻和视觉小说常有以下特征，必须主动化解：

- **特征：** 对话密集，内心戏和“吐槽（ツッコミ）”极多。
  - **处理：** 吐槽要快、准、狠。不要翻译成平铺直叙的陈述句，要带出反问、无奈或抓狂的语气。
- **特征：** 原文常有省略号、未完的话语（含糊其辞）、语气词连发。
  - **处理：** 中文可以用破折号、省略号配合语气词来还原空气感，但不要把「ええと」「あの」机械地全部译成“那个”、“怎么说呢”，要根据语境化为“呃……”、“我说……”或直接留白。
- **特征：** 独特的日系称谓与人称（仆、俺、私、前辈、欧尼酱）。
  - **处理：** 保持 ACG 翻译惯例。符合设定的前提下，“前辈”、“学姐”、“哥哥”可自然保留，这构成了作品的“风味”，但不要连句法也跟着日式。

## 叙述与描写规则

### 1. 动作要干脆，少用抽象名词
日轻的战斗或日常动作推进很快，不要加重读者的理解负担。
- 不宜：他对我进行了视线的投射。
- 宜：他看向我。 / 他的目光落在我身上。

### 2. 打碎“修饰语高塔”
日文喜欢把修饰语全堆在名词前面。中文必须拆成小短句，更符合轻小说的排版审美。
- 不宜：那个昨天还在和我吵架今天却红着脸递给我便当的青梅竹马。
- 宜：我的青梅竹马昨天还在跟我吵架，今天却红着脸，递给了我一份便当。

### 3. 让句子有落点与画面感
尽量把主语和核心动作提早说出来，让读者脑补出画面，然后再补充细节。

## 对话规则（重中之重）

### 1. 对话必须是“活人说的话”
读起来拗口、像译制片配音或学术论文的台词，一律重写。要符合角色的年龄和智商。

### 2. 角色声音辨识度
每个角色必须有独立的“语音库”。
- **傲娇：** 要口是心非，带点急躁或掩饰（“才、才不是特意为你做的呢！”）。
- **三无/冷淡：** 句子要短，没有多余的语气词，陈述客观事实（“了解。我会处理。”）。
- **轻浮/死党：** 用词随意，多反问和夸张（“喂喂，你小子也太惨了吧？”）。
- **大小姐：** 稍微正式、矜持，带点优雅或高傲（“这等小事，本就不该劳烦本小姐。”）。

### 3. 吐槽的艺术
日式吐槽（ツッコミ）的核心是“打破荒谬”。
- 原文：おいおい、それは冗談だろう。
- 太文绉绉：哎呀，你这莫非是在说笑吗。
- 太烂梗：喂喂喂，你这是在搞笑女吧？/ 小丑竟是我自己？
- **最适平衡：** 喂，你开玩笑的吧。 / 拜托，别闹了。

### 4. 节制语气词
不要满篇的“呢、啦、哦、呀、哟”。语气可以通过标点（！、？、……）和副词（到底、简直、果然）来体现。

## 翻译腔高危预警（避雷针）

看到以下结构，立即触发修改机制：

1. **“关于 / 对于”综合症**
   - ✖ “关于那件事，我感到很抱歉。”
   - ✔ “那件事，真的很抱歉。”
2. **“被”字滥用**
   - ✖ “他被大家所讨厌着。”
   - ✔ “大家都讨厌他。” / “他在班里很不受待见。”
3. **“进行 / 做出”等虚假动词**
   - ✖ “作出了拒绝”、“进行说明”。
   - ✔ “拒绝了”、“解释清楚”。
4. **无意义的复数“们”**
   - ✖ “学生们都看向了我。”
   - ✔ “全班都看向了我。” / “学生全盯住了我。”
5. **过长的定语“的”**
   - ✖ “带着像是看到了什么难以置信的东西的表情的她……”
   - ✔ “她神情错愕，像是看到了什么不可思议的东西……”

## 边界感与平衡把控（正反示例）

### 示例 1：情绪爆发（避免太僵硬，也避免太俗套）
- 场景：男主绝地反击时的怒吼。
- ✖ 僵硬：我要把你那无聊的幻想，在这里彻底粉碎掉！
- ✖ 烂梗：我直接就是一套素质连招把你的梦打碎！
- ✔ **平衡：** 你这无聊的幻想，就由我来亲手击碎！

### 示例 2：日常对话（去除书面感）
- 场景：朋友间的询问。
- ✖ 僵硬：你为何会在此处出现？
- ✖ 烂梗：你怎么在这，神马风把你吹来了？
- ✔ **平衡：** 你怎么在这儿？

### 示例 3：心理活动（增强网感与轻盈感）
- 场景：男主遇到麻烦时的内心独白。
- ✖ 僵硬：对于当前这种事态的发展，我感到十分头疼。
- ✖ 烂梗：家人们谁懂啊，这波我直接裂开。
- ✔ **平衡：** 事情变成这样，我头都大了。 / 这下麻烦大了。

## 禁止事项

1. 禁止逐句机械对齐原文语序。
2. 禁止让高中生/年轻人满口公文辞藻。
3. **禁止使用超出原作年代或世界观的网络流行烂梗。**
4. 禁止全篇角色共用一种毫无起伏的“机器翻译腔”。
5. 禁止在紧张的战斗或恐怖场景中使用冗长拖沓的复杂长句。

## 技术性硬性要求（控制符与日文残留）

这两条与文风无关，是“脚本还能不能正确渲染”和“译文能不能直接用”的底线：**与前面任何一条原则冲突时，以本节为准。**（项目里的 `缺控制符`、`残留日文` 两项检查盯的就是它们。）

### 1. 剧本内的控制符要尽可能保留

原文里的控制符（ruby 注音、字号/字体/颜色、换行、变量标记等）是给引擎看的指令，不是给读者看的文字。**标签本身一字不动，只翻译它包着的文字。**

- **ruby 注音**：如 `<rウェアウルフ>人狼</r>`（BGI 等引擎的写法）。开闭标签、标签名、大小写、`<` `>` 全部原样保留，只译被注音的词；`<r` 与 `>` 之间的假名读法按你的译名处理（同一个人名/名词全篇一致），但**不要因为读法不好处理就把标签删掉或只留一半**。
  - 原文：`<rウェアウルフ>人狼</r>の少女`
  - ✔ `<r沃尔夫>狼人</r>的少女`
  - ✖ `狼人的少女`（标签没了，引擎里注音也跟着没了）
- **字号 / 字体 / 颜色控制符**：`<size=30>`、`</size>`、`<font=...>`、`[color=...]` 之类，连同尖括号/方括号、标签名、`=` 与数值**原样保留**，位置也不要挪。
  - ✖ 原文 `「<size=30>混蛋！</size>」` → `「混蛋！」`（字号指令丢失，这句会以默认字号显示）
- **换行与转义**：`\n`、`\r\n`、`<br>` 等换行写法按原样保留（不要换成真实换行，也不要多一个少一个）；行内的 `%123;`、`<变量名>` 这类系统符号同样照抄。
- **数量与顺序**：原文有几个控制符，译文就得有几个——不合并、不重复、不漏、不挪位。译文比原文短，也不能顺手删掉“看起来多余”的标签。
- 拿不准某处控制符在中文里怎么处理时，**宁可原样保留**，也不要自作主张改写或省略。

### 2. 译文里不允许有日文残留

译文必须是干净的中文：假名一个都不该剩。以下都是常见残留，出现即算不合格。

- **促音、长音**：`っ`、`ッ`、`ー` 本身不发音，不能留在译文里。
  - ✖ `等一っ下！` / `好可ッ怕` / `呜哇ー`
  - ✔ `等一下！` / `好可怕` / `呜哇——`（拉长音用破折号或叠字，别留一个 `ー`）
- **语气词、语尾**：`ね`、`よ`、`な`、`わ`、`さ`、`ぞ`、`かな`、`かしら`、`っけ` 等一律化成中文语气（啊、嘛、吧、呢）或直接去掉，不允许以假名形式出现。
  - ✖ `是这样ね` / `走吧よ` / `真的吗かな`
  - ✔ `是这样啊` / `走吧` / `真的吗`
- **整词残留**：`はい`、`うん`、`ええ`、`いいえ`、`ごめん`、`ありがとう`、`お兄ちゃん`、`先輩` 之类必须译成中文（嗯、对、不、对不起、谢谢、哥哥、前辈），不能原样留在句子里。
  - ✖ `ええと、それはね……`
  - ✔ `呃……那个嘛。`
- **拟声词、感叹**：`あっ`、`うわっ`、`ふふ`、`へえ` 等按中文习惯处理成“啊、哇、嘿嘿、哦”，同样不保留假名。
- **符号**：日语的间隔符 `・` 不要带进中文，人名里的写法用中文的 `·`（如 `シャルル・ド・ゴール` → `夏尔·戴高乐`）。
- **专有名词**：人名、术语一律以**本项目的人名表与字典**为准；没收录时才自己定，定完全篇统一——但不能为了“保留风味”就把日文原名留在译文里。

## 自检清单（输出前最后把关）

- [ ] 这段对话，我能在脑海里给它配音吗？配出来像不像正常动画/日剧？
- [ ] 句子是不是有点太长了？能不能从中间劈开，用逗号或句号断句？
- [ ] 有没有不小心用了“对于”、“进行”、“被”这种生硬的词？
- [ ] 吐槽的情绪对不对？是不是足够干脆利落？
- [ ] 角色A和角色B说的话，把名字遮住，还能分得清谁是谁吗？
- [ ] 有没有夹带私货，用了让人尴尬的现代网络梗？
- [ ] 原文的控制符（ruby 注音、字号/字体标签、`\n`、变量标记）是不是一个不差、还在原来的位置上？
- [ ] 译文里还有假名吗？促音（っ）、语尾语气词（ね/よ/な）、`はい`/`ごめん` 这类整词，是不是都化成中文了？

**最终准绳：**
**把日轻译成中文，就是让角色在中文的语境里，用最符合他们性格的口吻，舒舒服服、活灵活现地再活一次。**
